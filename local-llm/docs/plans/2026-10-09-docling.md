# Conversion des PDF par Docling — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter à la stack `local-llm/` un overlay optionnel `docker-compose.docling.yml` qui fait convertir par
Docling les documents déposés dans Open WebUI, avec synchronisation de la configuration par `open-webui-init`, un PDF
d'exemple et la documentation.

**Architecture:** Un service `docling` (`docling-serve`, image CPU) sur le réseau interne ; Open WebUI l'appelle via
`CONTENT_EXTRACTION_ENGINE=docling`. Comme ces réglages relèvent de la PersistentConfig, `open-webui-init`
(`open-webui/configurer.py`) lit `GET /api/v1/retrieval/config` et aligne le moteur sur la présence de l'overlay
(variable `OPENWEBUI_DOCLING`), dans les deux sens. La décision est une fonction pure testée par `unittest`.

**Tech Stack:** Docker Compose, `quay.io/docling-project/docling-serve-cpu:v1.35.0`, Open WebUI 0.11.4 (image `main`),
Python 3 bibliothèque standard (`configurer.py`, tests `unittest`), `reportlab==5.0.1` via `uv run --with` (générateur
du PDF uniquement).

**Spec:** `local-llm/docs/specs/2026-10-09-docling-design.md`

```python
def docling_depuis_env(env):
    """Réglages Docling transmis par docker-compose.docling.yml, ou None si l'overlay n'est pas chargé."""
    if env.get("OPENWEBUI_DOCLING", "").lower() != "true":
        return None
    url = env.get("DOCLING_SERVER_URL", "")
    if not url:
        raise Echec("OPENWEBUI_DOCLING=true mais DOCLING_SERVER_URL est vide")
    try:
        params = json.loads(env.get("DOCLING_PARAMS") or "{}")
    except json.JSONDecodeError as e:
        raise Echec(f"DOCLING_PARAMS n'est pas du JSON valide : {e}") from None
    if not isinstance(params, dict):
        raise Echec("DOCLING_PARAMS doit être un objet JSON, par exemple {\"do_ocr\": \"false\"}")
    return {"url": url, "params": params}


def reglage_extraction(config, docling):
    """Champs à envoyer à /api/v1/retrieval/config/update (None si rien à changer) et libellé d'état.

    Overlay chargé : Docling, avec l'URL et les paramètres de l'overlay. Overlay retiré : retour à l'extracteur
    intégré, seulement si le moteur est encore Docling (un autre moteur, choisi à la main, est respecté).
    """
    moteur = config.get("CONTENT_EXTRACTION_ENGINE") or ""
    if docling:
        voulu = {"CONTENT_EXTRACTION_ENGINE": "docling", "DOCLING_SERVER_URL": docling["url"],
                 "DOCLING_PARAMS": docling["params"]}
        if all(config.get(cle) == valeur for cle, valeur in voulu.items()):
            return None, "Docling (inchangé)"
        return voulu, "Docling (réglé)"
    if moteur == "docling":
        return {"CONTENT_EXTRACTION_ENGINE": ""}, "extracteur intégré (Docling retiré)"
    return None, f"{moteur or 'extracteur intégré'} (inchangé)"


def synchroniser_extraction(jeton, docling):
    config = appel("GET", "/api/v1/retrieval/config", jeton)
    champs, etat = reglage_extraction(config, docling)
    if champs:
        appel("POST", "/api/v1/retrieval/config/update", jeton, champs)
    print(f"extraction des documents : {etat}")
```

```yaml
# Service optionnel Docling : convertit en Markdown les documents déposés dans Open WebUI (PDF, DOCX, PPTX, XLSX…)
# en analysant la mise en page : tableaux restitués en tableaux, en-têtes et pieds de page écartés, titres
# conservés. Voir le tutoriel 01, section 6.2.1.
# Activation : ajouter docker-compose.docling.yml à COMPOSE_FILE dans .env (voir .env.example), par exemple
#   COMPOSE_FILE=docker-compose.yml:docker-compose.docling.yml
#   COMPOSE_FILE=docker-compose.yml:docker-compose.vulkan.yml:docker-compose.n8n.yml:docker-compose.docling.yml
# (sous Windows hors WSL, le séparateur est ";")
#
# Open WebUI ne lit ses variables d'extraction qu'au premier démarrage (PersistentConfig) : sur une installation
# existante, c'est open-webui-init qui applique ces réglages, et qui revient à l'extracteur intégré si l'overlay
# est retiré.
#
# Les réglages ne sont écrits qu'ici, et transmis à open-webui comme à open-webui-init.
# OCR désactivé : il ne sert qu'aux PDF scannés et multiplie le temps de conversion (tutoriel 01, section 6.2.1).
x-docling-env: &docling-env
  DOCLING_SERVER_URL: http://docling:5001
  DOCLING_PARAMS: '{"do_ocr": "false", "table_mode": "accurate"}'

services:
  docling:
    restart: unless-stopped
    image: quay.io/docling-project/docling-serve-cpu:v1.35.0
    environment:
      # Open WebUI appelle la conversion synchrone : au-delà de ce délai (120 s par défaut), elle échoue en HTTP 504.
      - DOCLING_SERVE_MAX_SYNC_WAIT=1800
    mem_limit: ${DOCLING_MEM_LIMIT:-6g}
    # Aucun port publié : seul Open WebUI l'appelle, sur le réseau interne de la stack.
    healthcheck:
      test: ["CMD", "python3", "-c", "import urllib.request; urllib.request.urlopen('http://localhost:5001/ready', timeout=5)"]
      interval: 10s
      timeout: 10s
      retries: 30
      start_period: 60s   # chargement des modèles de mise en page au démarrage

  open-webui:
    environment:
      <<: *docling-env
      CONTENT_EXTRACTION_ENGINE: docling
    depends_on:
      docling: { condition: service_healthy }

  open-webui-init:
    environment:
      <<: *docling-env
      OPENWEBUI_DOCLING: "true"
    depends_on:
      docling: { condition: service_healthy }
```

```python
"""Génère matrice-acteurs-heron.pdf, PDF fictif du Projet Héron pour comparer les extracteurs d'Open WebUI.

Le document réunit ce que l'extracteur intégré lit mal (tutoriel 01, section 6.2) : un sommaire, des tableaux à
plusieurs colonnes aux valeurs proches d'une ligne à l'autre, un pied de page répété sur chaque page.

Depuis local-llm/ : uv run --with reportlab==5.0.1 open-webui/exemples/generer-pdf.py
"""
from pathlib import Path

from reportlab.lib import colors
from reportlab.lib.pagesizes import A4
from reportlab.lib.styles import getSampleStyleSheet
from reportlab.lib.units import cm
from reportlab.platypus import PageBreak, Paragraph, SimpleDocTemplate, Spacer, Table, TableStyle

SORTIE = Path(__file__).with_name("matrice-acteurs-heron.pdf")
PAGES = 3
STYLES = getSampleStyleSheet()

ACTEURS = [
    ["Organisation", "Rôle", "Classification\ndes données", "Accès au\nréférentiel SysML", "Statut"],
    ["Acme Défense", "Maître d'ouvrage", "Niveau 3", "Lecture/écriture", "Validé"],
    ["Novaltis", "Titulaire du marché", "Niveau 2", "Lecture/écriture", "Validé"],
    ["Orbitec Systèmes", "Sous-traitant outillage", "Niveau 1", "Lecture seule", "En attente"],
    ["Bureau Vertex", "Audit qualité", "Niveau 2", "Aucun", "Validé"],
]
LIVRABLES = [
    ["Livrable", "Exigence", "Responsable", "Relecteur", "Échéance"],
    ["Rapport d'inventaire des modèles", "EX-01", "Novaltis", "Acme Défense", "Mois 2"],
    ["Plan de migration", "EX-05", "Novaltis", "Bureau Vertex", "Mois 6"],
    ["Rapport final", "EX-08", "Novaltis", "Acme Défense", "Mois 9"],
    ["Guide de modélisation mis à jour", "EX-10", "Acme Défense", "Novaltis", "Mois 10"],
]


def tableau(lignes, largeurs):
    t = Table(lignes, colWidths=[l * cm for l in largeurs], repeatRows=1)
    t.setStyle(TableStyle([
        ("FONTNAME", (0, 0), (-1, 0), "Helvetica-Bold"),
        ("BACKGROUND", (0, 0), (-1, 0), colors.lightgrey),
        ("GRID", (0, 0), (-1, -1), 0.5, colors.grey),
        ("VALIGN", (0, 0), (-1, -1), "MIDDLE"),
    ]))
    return t


def pied_de_page(canvas, doc):
    canvas.saveState()
    canvas.setFont("Helvetica", 8)
    canvas.drawCentredString(A4[0] / 2, 1.2 * cm,
                             f"Projet Héron – Diffusion restreinte – © Novaltis 2026 – page {doc.page}/{PAGES}")
    canvas.restoreState()


def contenu():
    titre, h1, texte = STYLES["Title"], STYLES["Heading1"], STYLES["BodyText"]
    return [
        Paragraph("Projet Héron – Annexe C : matrice des acteurs et des livrables", titre),
        Paragraph("Document fictif, établi pour les exercices de la formation.", texte),
        Spacer(1, 0.6 * cm),
        Paragraph("Sommaire", h1),
        Paragraph("1. Objet de l'annexe", texte),
        Paragraph("2. Acteurs et classification des données", texte),
        Paragraph("3. Livrables et responsables", texte),
        Paragraph("4. Calendrier", texte),
        Spacer(1, 0.6 * cm),
        Paragraph("1. Objet de l'annexe", h1),
        Paragraph("Cette annexe complète la proposition technique de Novaltis pour la migration des modèles "
                  "SysML v1 d'Acme Défense vers SysML v2. Elle précise, pour chaque organisation, son rôle, le "
                  "niveau de classification des données qu'elle manipule et ses droits sur le référentiel de "
                  "modèles, puis répartit les livrables contractuels.", texte),
        PageBreak(),
        Paragraph("2. Acteurs et classification des données", h1),
        Paragraph("Le niveau de classification fixe les données auxquelles chaque organisation a accès. Une "
                  "organisation au statut « En attente » n'intervient pas avant la validation de son habilitation "
                  "par Acme Défense.", texte),
        Spacer(1, 0.4 * cm),
        tableau(ACTEURS, [3.6, 4.2, 2.8, 3.4, 2.4]),
        PageBreak(),
        Paragraph("3. Livrables et responsables", h1),
        Paragraph("Chaque livrable a un responsable, qui le rédige, et un relecteur, qui le valide avant sa "
                  "remise au comité de pilotage.", texte),
        Spacer(1, 0.4 * cm),
        tableau(LIVRABLES, [5.4, 2.0, 3.0, 3.0, 2.2]),
        Spacer(1, 0.6 * cm),
        Paragraph("4. Calendrier", h1),
        Paragraph("Le projet démarre en janvier 2027. Le comité de pilotage se réunit tous les deux mois ; les "
                  "échéances sont exprimées en mois après le démarrage.", texte),
    ]


def main():
    doc = SimpleDocTemplate(str(SORTIE), pagesize=A4, bottomMargin=2.5 * cm,
                            title="Projet Héron – Annexe C", author="Novaltis (fictif)")
    doc.build(contenu(), onFirstPage=pied_de_page, onLaterPages=pied_de_page)
    print(f"{SORTIE.name} : écrit")


if __name__ == "__main__":
    main()
```

```python
"""Indexe le PDF d'exemple dans Open WebUI puis pose les questions de test (sortie : réponses et sources)."""
import json, os, sys, time, urllib.request, uuid
from pathlib import Path

URL = "http://localhost:3000"
PDF = Path(sys.argv[1])
MODELE = os.environ.get("LLM_MODEL", "granite4.2:8b")
QUESTIONS = [
    "Quelle classification des données s'applique à Orbitec Systèmes ?",
    "Quelles organisations ont un accès en lecture/écriture au référentiel SysML ?",
    "Qui relit le plan de migration, et quelle est son échéance ?",
    "Qui est responsable du guide de modélisation mis à jour ?",
]
OUVREUR = urllib.request.build_opener(urllib.request.ProxyHandler({}))


def appel(methode, chemin, jeton=None, corps=None, donnees=None, type_contenu=None, delai=900):
    entetes = {"Authorization": f"Bearer {jeton}"} if jeton else {}
    if corps is not None:
        donnees, type_contenu = json.dumps(corps).encode(), "application/json"
    if type_contenu:
        entetes["Content-Type"] = type_contenu
    with OUVREUR.open(urllib.request.Request(URL + chemin, data=donnees, headers=entetes, method=methode),
                      timeout=delai) as r:
        return json.loads(r.read() or b"null")


jeton = appel("POST", "/api/v1/auths/signin",
              corps={"email": os.environ["WEBUI_ADMIN_EMAIL"], "password": os.environ["WEBUI_ADMIN_PASSWORD"]})["token"]
print("moteur :", appel("GET", "/api/v1/retrieval/config", jeton).get("CONTENT_EXTRACTION_ENGINE") or "intégré")
f = uuid.uuid4().hex
corps = (f"--{f}\r\nContent-Disposition: form-data; name=\"file\"; filename=\"{PDF.name}\"\r\n"
         "Content-Type: application/pdf\r\n\r\n").encode() + PDF.read_bytes() + f"\r\n--{f}--\r\n".encode()
debut = time.monotonic()
fichier = appel("POST", "/api/v1/files/", jeton, donnees=corps, type_contenu=f"multipart/form-data; boundary={f}")
while (etat := appel("GET", f"/api/v1/files/{fichier['id']}/process/status", jeton)).get("status") not in ("completed", "failed"):
    time.sleep(2)
print(f"indexation : {etat.get('status')} en {time.monotonic() - debut:.0f} s (fichier {fichier['id']})")
for q in QUESTIONS:
    r = appel("POST", "/api/chat/completions", jeton, {
        "model": MODELE, "stream": False, "messages": [{"role": "user", "content": q}],
        "files": [{"type": "file", "id": fichier["id"]}]})
    print(f"\n### {q}\n{r['choices'][0]['message']['content']}")
```

````markdown
#### 6.2.1 Activer Docling pour les PDF

[Docling](https://github.com/docling-project/docling-serve) convertit chaque document en Markdown en analysant sa mise en page. Une fois activé, Open WebUI lui envoie tous les fichiers déposés, sauf le Markdown et le texte brut qu'il lit lui-même : les PDF, mais aussi les DOCX, PPTX et XLSX.

**Coût**, mesuré sur la configuration de référence :

| | |
|---|---|
| Image Docker | {TAILLE_IMAGE} à télécharger une fois |
| Mémoire | {MEMOIRE_REPOS} au repos, jusqu'à {MEMOIRE_PIC} pendant une conversion (plafond : `DOCLING_MEM_LIMIT` dans `.env`) |
| Démarrage | ~{DUREE_DEMARRAGE} avant qu'Open WebUI ne démarre (chargement des modèles de mise en page) |
| Conversion | ~{SECONDES_PAR_PAGE_RETENU} par page ; un PDF de {PAGES_LONG_PDF} pages : {DUREE_LONG_PDF} |

L'indexation d'un PDF est donc nettement plus lente qu'avec l'extracteur intégré : c'est le prix de la structure.

**Activer** : ajouter `:docker-compose.docling.yml` à la fin de la ligne `COMPOSE_FILE` de `.env`, puis :

```bash
docker compose up -d
docker compose ps docling                  # doit afficher "(healthy)"
docker compose logs open-webui-init        # "extraction des documents : Docling (réglé)"
```

Open WebUI ne lit ses variables d'extraction qu'au premier démarrage (PersistentConfig, section 2) : c'est donc `open-webui-init` qui bascule une installation existante sur Docling. Le réglage est visible dans *Admin Panel → Settings → Documents → Content Extraction Engine*. Les documents déjà indexés ne sont pas reconvertis : pour en profiter, les retirer de la base et les ajouter à nouveau.

**Désactiver** : retirer `:docker-compose.docling.yml` de `COMPOSE_FILE`, puis `docker compose up -d --remove-orphans`. `open-webui-init` affiche alors « extraction des documents : extracteur intégré (Docling retiré) ». Sans cette bascule, Open WebUI continuerait d'envoyer les fichiers à un service arrêté, et chaque dépôt échouerait.

> Comme pour le modèle de base, relancer `open-webui-init` remet le moteur d'extraction aux valeurs de l'overlay. Un autre moteur choisi à la main dans l'interface (Tika, par exemple) n'est conservé que si l'overlay n'est pas chargé.

**PDF scannés (OCR)** : l'OCR est désactivé, car il ne sert qu'aux PDF sans texte et multiplie le temps de conversion. Pour l'activer, remplacer `"do_ocr": "false"` par `"do_ocr": "true"` dans `docker-compose.docling.yml` (variable `DOCLING_PARAMS`), puis `docker compose up -d`.
````
